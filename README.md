# 双 AI 对话实验室

**Dual AI Dialogue Lab** 是一个用于 ChatGPT 与 DeepSeek 网页多轮对话接力的浏览器扩展项目，提供任务记录、运行诊断和失败回退功能。

## 当前版本

**v0.10.9 — 预发布版（Pre-release）**

本版本供试用。不同浏览器和网页状态可能影响附件投递效果，重要任务请先进行测试。

## 主要功能

- 在 ChatGPT 与 DeepSeek 之间进行多轮对话接力。
- 保存任务记录，方便回顾对话过程。
- 提供诊断信息和失败回退机制。
- 支持通过网页附件控件投递原始文件。
- 不执行本地 OCR，不应仅凭文件名推断文件内容。

## 下载与安装

前往 [v0.10.9 Release 页面](https://github.com/LPLS-ZG/dual-ai-dialogue-lab/releases/tag/v0.10.9)，下载 `dual-ai-dialogue-lab-v0.10.9-release.zip`。

安装步骤：

1. 下载 ZIP 并解压到电脑文件夹。
2. Chrome 用户打开 `chrome://extensions`；Edge 用户打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择实际包含 `manifest.json` 的文件夹。

更新前建议备份重要的本地记录。
