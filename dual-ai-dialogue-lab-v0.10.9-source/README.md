# 双 AI 对话实验室 v0.10.2 源码包

- `install/`：可加载到 Edge/Chrome 的扩展目录。
- `test_v094.js`、`test_v095.js`、`test_v096.js`：继承回归测试。
- `test_v097.js`：附件阶段进度、超时边界与诊断回归。
- `test_v098.js`、`test_v099.js`：文件名别名和输入区附近附件证据测试。
- `test_v0102.js`：原生 FileList 证据通道与基线签名测试。
- `CHANGELOG_v0.10.1.md`：变更记录。
- `TEST_REPORT_v0.10.1.md`：自动测试结果与验收边界。

注意：自动化代码测试不等同于真实登录态网页端到端测试。


## v0.10.2 附件识别修复

针对网页已接收文件但附件名不出现在可访问 DOM 文本中的情况，新增原生 `input.files` 独立证据通道，并记录上传前文件列表签名，避免旧选择残留误判。

## v0.10.1 附件识别修复

针对网页附件卡片可能位于 open shadow root、以及大尺寸包装节点导致局部扫描漏报的情况，核验器改为遍历 composed DOM，并在失败诊断中输出文件名计数、基线、命中节点和输入区位置。
